# Brightside Dental — Business Website

A fictional dental clinic website created for a college group project. The site is built with HTML and CSS, uses PicoCSS for its base styles, and is published with GitHub Pages.

## Pages

- **Repository:** <https://github.com/LeviM-0323/Lab-5-Business-Website>
- **Live website:** <https://levim-0323.github.io/Lab-5-Business-Website/>

The GitHub Actions workflow in `.github/workflows/static.yml` publishes the repository to GitHub Pages when changes are pushed to `main`.

## Project files

- `index.html` — page content, semantic structure, and PicoCSS stylesheet link

The site relies on PicoCSS for its styling and does not need a custom CSS file. The clinic name, address, phone number, email, and opening hours are fictional sample details. Replace them with the group's chosen details before presenting the site as anything other than a class-project demo. The stylesheet and photography are loaded from external services, so those assets require an internet connection.
